# 数据格式

message.eml 是带 CRLF 的原始邮件。fetch-session.bin 是 IMAP 应答字节，FETCH literal 的长度按 UTF-8 原件字节计算，正文内也包含类似 tagged response 的文字。partial-literal.bin 在 literal 正文中断开。mailboxes.json 给出虚构文件夹的两个 UIDVALIDITY。inspectMail 只解析已完整保存邮件的头部并计算摘要。

所有企业、设备、记录和站点均为虚构。二进制原件的长度及摘要见 fixtures/manifest.json，运行时不需要访问这些网址。
